# Descript.ion comments

[English](README.md) | 简体中文

让 Obsidian 支持对文件与文件夹**备注**

所有备注保存在对应目录下的 `descript.ion` 文件中（这是一种被诸多文件管理器广泛采用的同级纯文本注释标准）。纯本地运行、零网络请求，在 Obsidian 与外部文件管理器之间实现无缝双向互通。

---

## ✨ 核心特性

- 📝 **便捷编辑**：在文件列表右键任意文件、附件或文件夹，即可快速添加、修改或删除备注；支持多行输入。
- 👁️ **悬停预览**：鼠标悬停在文件列表中的任意项目上，即时弹出纯文本备注浮窗，无需点开即可快速查阅。
- 📌 **状态栏常驻**：底部状态栏实时显示当前活动笔记的备注；鼠标悬停查看完整内容，点击直达编辑弹窗。
- 🔄 **生命周期自动同步**：在 Obsidian 内对文件进行重命名、删除或跨目录移动时，自动维护对应备注。
- 🛡️ **零侵入**：不污染 Markdown 正文，脱离 Obsidian 仍能正常使用。

## 📖 使用指南

### 1. 编辑与删除备注
- **打开编辑**：
  - 在文件列表（文件资源管理器）中，**右键**点击目标文件或文件夹，选择 **编辑备注**。
  - 或者直接**点击底部状态栏**的备注区域（无备注时显示 **添加备注**）。
- **快捷键操作**：
  - `Enter`：换行输入多行内容。
  - `Ctrl` / `Cmd` + `Enter`：保存备注。
  - `Escape`：取消并关闭弹窗。
- **删除备注**：
  - 点击弹窗左下角的 **删除备注** 按钮；
  - 或者将输入内容清空（或输入全空白字符）后点击保存。

### 2. 悬停查看备注
- 鼠标悬停在文件列表中的笔记、附件、图片或文件夹名称上，即可在条目下方显示备注预览浮窗。
- 浮窗以纯文本字面量显示备注内容（完整保留换行与空格），移开鼠标后约 150ms 自动关闭。
- 如果外部程序（如 Total Commander）更新了备注，下次悬停时即可立即看到最新内容。

### 3. 状态栏集成
- 在编辑器中打开笔记时，底部状态栏会显示该笔记的备注信息。
- 当备注内容较长时，状态栏会自动省略截断；将鼠标悬停在状态栏文字上可查看完整多行内容。
- 点击状态栏文字可随时唤起编辑弹窗。
- 当未激活任何文件，或处于不支持备注的对象时，状态栏入口会自动隐藏。

### 4. 文件移动与自动维护
插件会在后台自动维护 `descript.ion` 的一致性：
- **同目录重命名**：自动将原备注条目更新为新名称。
- **跨目录移动**：自动将备注从原目录迁移到目标目录的 `descript.ion` 中。
- **删除文件/文件夹**：自动移除对应的备注条目；如果某个目录下已无任何备注条目，插件会自动删除空的 `descript.ion` 文件。

## ⚙️ 格式与兼容性说明

- **存储规范**：采用标准 UTF-8 编码（带 BOM）及 CRLF 行分隔符，名称含空格时自动加双引号包裹。
- **多行转义**：遵循 Total Commander 标准的多行转义规则，与外部工具双向互通毫无障碍。
- **备注范围**：仅为 Vault 内部的常规文件与文件夹提供备注；Vault 根目录及 `descript.ion` 文件本身不接受备注。
- **单条容量**：单条完整记录（含文件名、转义及标记）最长支持 4096 字节。

## 📥 安装方法

### 方式一：社区插件市场（推荐）
*(上架后可用)*
1. 打开 Obsidian **设置** → **社区插件**。
2. 关闭“受限模式”，点击 **浏览**。
3. 搜索 `Descript.ion comments` 并安装。
4. 安装完成后点击 **启用**。

### 方式二：手动安装
1. 从 [GitHub Releases](https://github.com/Myraxion/obsidian-descript-ion/releases) 下载最新发布的发布包文件（`main.js`、`manifest.json`、`styles.css`）。
2. 在您的 Obsidian 库目录下，找到或新建插件目录：
   `<Vault>/.obsidian/plugins/descript-ion/`
3. 将下载的 `main.js`、`manifest.json`、`styles.css` 放置到该目录下。
4. 打开 Obsidian **设置** → **社区插件**，重新加载并启用 **Descript.ion comments**。

## ❓ 常见问题

<details>
<summary><b>为什么提示“备注文件不是合法 UTF-8，无法修改”？</b></summary>
为了保障您的数据绝对安全，插件遵循“遇异常只读保护”的原则。如果现有 <code>descript.ion</code> 包含 ANSI 编码、重复条目、异常损坏格式或第三方未知标记，插件会拒绝写入以避免破坏原文件。建议在外部工具中将该备注文件另存为 UTF-8 格式后再试。
</details>

<details>
<summary><b>Windows 下隐藏的 descript.ion 会被解除隐藏吗？</b></summary>
保存完成后仍为隐藏文件（+H）。插件先写入临时文件，再安全替换原文件；Windows 替换期间会暂时清除原文件的隐藏属性，成功或失败后恢复，不会通过原地覆盖破坏旧备注。
</details>

<details>
<summary><b>移动或重命名失败会丢失备注吗？</b></summary>
不会。在跨目录移动或重命名时，若遇到目标冲突或文件写入失败，插件会安全保留源记录并弹出明确提示，防止数据静默丢失。
</details>
