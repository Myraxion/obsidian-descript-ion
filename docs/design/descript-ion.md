## 已确认的目标

插件在 Obsidian 内查看、编辑与维护兼容 Total Commander 的 UTF-8 descript.ion 备注。

用户要求的功能：文件列表悬浮备注、右键编辑弹窗、移动/重命名/删除同步、删除无剩余备注的 descript.ion、状态栏查看与点击编辑、命令面板清理当前目录或整库的孤立备注。

## 已确认的范围

- 操作入口是 Obsidian 文件资源管理器。
- 备注对象覆盖当前 Vault 内的文件夹、笔记和附件。
- 文件夹的备注存放于其父目录的 descript.ion。
- Vault 根目录本身不提供备注。
- 首版仅支持 UTF-8；遇到其他编码或无法识别的文件时提示原因、保持原文件，不自动转码。
- 首版以桌面端为验收目标，暂不承诺移动端交互与同步支持。
- 插件 ID 为 `descript-ion`，显示名为 `Descript.ion comments`，首版操作文案使用简体中文。
- `descript.ion` 本身不作为备注对象。

## 已确认的行为

### 兼容与写回

- 读取接受带或不带 BOM 的合法 UTF-8，以及 CR、LF、CRLF 换行。
- 成功保存时统一写为 UTF-8 BOM 与 CRLF；不额外添加开头空行，多行备注使用 TC 扩展标记。
- 纯 ASCII 字节也是合法 UTF-8，不尝试推断文件的创建程序或原始编码意图。
- 存在未知程序标记、重复名称或无法解析记录时，整个备注文件只读；提示原因，跳过编辑、自动维护与清理。
- 只有确认没有剩余备注或未知内容时才能删除备注文件。
- 完整序列化记录（含文件名、空格、转义、程序标记与 CRLF）不得超过 4096 字节。这是项目采取的保守限制，不将 CRLF 的计数方式宣称为已核验的 TC 官方规则。
- 超限时拒绝保存并保留输入；重命名导致超限时跳过备注同步并提示。
- 空字符串或全空白输入视为删除备注；非空备注保留用户输入的空格与换行。
- 删除最后一条备注后直接删除备注文件。

### 生命周期与交互

- 自动维护只保证 Obsidian 内的移动、重命名与删除。外部操作没有可靠旧路径时不猜测备注迁移。
- 接受为文件资源管理器 Tooltip 使用小型 DOM 兼容层；Obsidian 更新后可能需要调整此层。
- 文件树 Tooltip 与文件名左边缘对齐，下方优先、空间不足翻到上方，间距 8px；最大 320px × 160px，超高直接裁切，全文通过右键编辑查看。提示不接收鼠标交互，离开条目约 150ms 关闭；官方提示保持现状，不保证所有场景都无重叠。
- 状态栏以当前活动文件为目标，点击编辑该文件备注；长备注截断显示，悬浮显示全文。
- 文件夹备注通过文件资源管理器右键编辑。
- 移动目标位置已有同名备注条目时，跳过备注同步、保留两边记录并提示冲突；不回滚已经完成的文件移动。
- 跨目录迁移先保存目标备注，成功后才删除源备注。目标写入失败时保留源记录；源删除失败时保留重复记录，两种情况均提示同步失败。
- 弹窗打开后备注文件发生外部修改，保存前发现内容变化时暂停保存、保留用户输入并提示重新载入后处理；首版不自动合并。
- 活动文件无备注时状态栏显示“添加备注”；无活动文件时隐藏状态栏项、禁用当前目录清理命令，整库清理仍可执行。
- 用户直接移动、重命名或删除备注文件时，刷新相关目录的备注显示，不自动重建备注文件或搬迁其中的记录。
- 整个文件夹移动时，内部备注文件随目录移动，条目保持相对名称；维护该文件夹在父目录中的备注。
- 弹窗打开期间目标文件被移动、重命名或删除时，暂停保存、保留输入，提示重新打开目标。
- 编辑弹窗使用纯文本多行输入框，提供“保存”“删除备注”“取消”；Enter 换行，Ctrl/Cmd+Enter 保存，Escape 取消。
- Tooltip 与状态栏按纯文本显示备注，不渲染 Markdown 或 HTML。
- 悬浮文件条目、打开编辑弹窗、操作状态栏或切换活动文件时重新读取备注；不要求无交互时实时刷新。

### 孤立备注清理

- 当前目录指当前活动文件的父目录，只清理这一层。
- 整库清理递归扫描内容目录，排除 `.obsidian`、`.trash` 等内部目录。
- 用实际存储中的存在性判断孤立备注，不把文件列表中的不可见对象当成不存在。
- 清理完成后报告删除条目数与跳过文件数。
- 孤立备注扫描只由清理命令触发，不在启动或后台自动扫描删除；日常删除事件仍维护对应备注条目。
- 清理命令删除零字节、仅有 BOM 或仅有空行的备注文件，并报告删除的备注文件数；未知内容或解析失败的文件跳过。

## 调研事实与限制

### Total Commander

- UTF-8 BOM 是 `EF BB BF`。`0D 0A` 是 CRLF，不是 BOM 的组成部分；未核验到必须使用五字节头的要求。TC 接受 CR、LF 与 CRLF 行结束符。含空格的名称需要双引号。[TC 作者的格式说明](https://www.ghisler.ch/board/viewtopic.php?t=85478)
- TC 多行备注使用程序扩展标记；UTF-8 字节尾为 `04 C3 82`。只有具备 TC 标记的备注才解释字面 `\n` 为换行、`\\` 为反斜杠，不能对普通单行备注无条件解码。[UTF-8 扩展说明](https://www.ghisler.ch/board/viewtopic.php?t=45843)、[转义与长度说明](https://ghisler.ch/board/viewtopic.php?start=45&t=11238)
- 4KB 预算包括文件名、分隔空格和扩展字段；是否包括 CRLF 尚未从官方材料核验。本项目已决定采用完整序列化行含 CRLF 不超过 4096 字节的保守约束。[长度说明](https://ghisler.ch/board/viewtopic.php?start=45&t=11238)
- descript.ion 基础格式与 TC 多行扩展需要区分。用户材料中的 gpsoft 应为 JP Software / JPSoft。原始字段规范目前未能从官方原文核验；项目已决定对未知程序标记采取整个文件只读的策略。[当前 JPSoft DESCRIBE 文档](https://www.jpsoft.com/help/describe.htm)

### Obsidian

通过 Context7 查询官方仓库 `/obsidianmd/obsidian-developer-docs`，并补查官方 API 类型。

- Vault 只访问应用内可见文件，不能用其查询结果为空推定磁盘文件不存在；隐藏目录需要 Adapter。未知扩展 `.ion` 是否始终成为 TFile 没有找到保证。[Vault 指南](https://docs.obsidian.md/Plugins/Vault)
- DataAdapter 提供二进制读写、存在性检查与非递归列目录；文本 process 不能提供跨两个备注文件的事务，也没有找到与 TC 外部写入互斥的保证。[DataAdapter 文档](https://github.com/obsidianmd/obsidian-developer-docs/blob/main/en/Reference/TypeScript%20API/DataAdapter.md)
- rename 提供对象及 oldPath，delete 提供对象；目录子项事件次数与外部移动是否被识别成 rename 没有公开保证。[Vault 事件](https://github.com/obsidianmd/obsidian-developer-docs/blob/main/en/Reference/TypeScript%20API/Vault.md)
- file-menu 可用于文件与文件夹右键菜单；状态栏不支持移动端。[右键菜单](https://docs.obsidian.md/Plugins/User+interface/Context+menus)、[状态栏](https://docs.obsidian.md/Plugins/User+interface/Status+bar)
- 公共 API 有 setTooltip，但未找到文件资源管理器条目悬浮钩子的公开契约；可能需要依赖 DOM 的兼容层。[官方 API 类型](https://github.com/obsidianmd/obsidian-api/blob/master/obsidian.d.ts)
