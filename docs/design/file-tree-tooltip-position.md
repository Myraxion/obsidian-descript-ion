# 文件树备注 Tooltip 位置与尺寸

2026-10-09，通过 grill-with-docs 讨论调整现有备注 Tooltip，降低与 Obsidian 官方时间 Tooltip 重叠的概率。

## 已确认

- 保留独立的备注 Tooltip，通过固定位置降低冲突概率；不检测官方 Tooltip 的实际位置，也不保证所有场景都无重叠。
- 备注 Tooltip 默认放在对应条目下方，下方空间不足时翻到上方。
- 尺寸限制仅作用于插件的备注 Tooltip，Obsidian 官方时间 Tooltip 保持现状。
- 最大宽度 320px；短备注按内容收缩，长行自动换行，窄窗口中进一步缩小以保持可见。
- 最大高度 160px；超出高度的内容直接裁切，不提供滚动；存储中的备注全文不变。
- Tooltip 不接收鼠标交互，鼠标移入不会延长显示。此规则为用户随后明确修改的要求，替代原先的移入保持与滚动阅读方案。

## 放置与交互规则

- 按提示框实际高度判断下方空间，不足时翻到上方；左右保持在窗口内，上方也不足时缩小显示区域。
- 离开条目后约 150ms 关闭，返回原条目可取消关闭。进入另一条目时立即清除旧提示，再读取新备注。
- 提示竖直方向贴着条目边缘放置。
- 保留每次悬浮重新读取、纯文本显示、无备注不显示以及卸载清理的既有行为。
- 自动检查类型、构建、lint 和现有服务测试；用户手动验收下方与上方放置、窗口边缘、超高裁切、移入不保持和切换条目。

用户随后调用 implement 技能，授权按完整方案实施。
