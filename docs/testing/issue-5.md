# Issue #5 验收记录

任务：[同目录重命名与删除时维护备注](https://github.com/Myraxion/obsidian-descript-ion/issues/5)。

## 交付说明

在 Obsidian 内同目录重命名或删除文件/文件夹后，其父目录中的备注同步更新或删除：

1. **同目录文件重命名**：文件在同一目录重命名后，父目录 `descript.ion` 中条目名称更新为新名称，完整保留原有备注内容与格式（单行、多行、TC 标记、空格引号、换行与转义）。同目录下其他文件的备注不受影响。
2. **文件夹重命名**：文件夹重命名仅维护其在父目录中的备注条目；文件夹内部随之移动的 `descript.ion` 保持其相对条目不变，不被逐个重写。
3. **删除操作与文件清理**：删除文件或文件夹后，同步删除父目录中的对应条目；最后一条备注删除后自动清理并移除 `descript.ion` 文件；不会在已删除的目录中重建或写入任何元数据。
4. **冲突与超限保护**：目标名称已有条目时，保留既有记录与原记录并弹出冲突提示；重命名导致序列化记录超过 4096 字节时，保留原记录并弹出提示；两者均不回滚 Obsidian 内已完成的对象操作。
5. **只读保护与存储错误**：父目录备注文件为非合法 UTF-8、含未知程序标记、重复名称或异常记录时，沿用全文件不可修改保护；存储读写失败明确提示，受保护原始字节保持不变。
6. **元数据操作与显示刷新**：用户直接移动、重命名或删除 `descript.ion` 时，不作为备注对象迁移或重建条目，并刷新状态栏等相关显示；整目录移动时随目录移动的备注文件按元数据处理。
7. **已打开弹窗保护**：编辑弹窗打开后，若目标被重命名或删除，尝试保存或删除备注时被拦截并提示目标已改变，保留输入框内容，不会保存至旧路径。
8. **生命周期管理**：生命周期监听器在插件卸载与禁用时完全注销；插件加载与重载时不触发无关的全库扫描与维护。
9. **Windows 隐藏属性支持**：在 Windows 系统下生成或写入 `descript.ion` 时，自动设置隐藏属性（`+H`），保持与 Total Commander 的默认隐藏文件规范完全一致。
