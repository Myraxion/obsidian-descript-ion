环境：Obsidian 1.14.4、Total Commander 11.58，测试 Vault `D:\Libraries\Obsidian\Demo\`。用户已确认[设计及四项取舍](../design/unified-file-tree-tooltip.md)，真实应用验收由用户手动完成。

## 自动验证

回归通过插件注册入口及模拟的 DOM/Obsidian 边界验证：原生 1000 ms 延迟与备注入口不会产生两个提示、200 ms 下限、一次显示完整的纯文本与官方信息、文件和目录分支、慢读取不先显示、无备注恢复、错误原因合并、外部删除备注、Page preview 事件参数、离开/卸载后无残留、重新启用不重复、旧读取不覆盖新内容。

修改前 `npm test` 复现 2 个提示及过早显示的断言失败。此测试没有运行真实 Obsidian，原生 Tooltip 渲染、位置、本地化及 Page preview UI 均由以下手动验收覆盖。

## 用户手动验收

1. 更新三个产物后禁用再启用插件。悬浮有备注的笔记与附件，确认约 200 ms 后一次出现完整提示，上方备注、下方官方信息；继续停留数秒也不会叠加第二个提示、追加内容或重新定位。
2. 禁用插件对照文件原提示：修改、创建时间一致，格式 YYYY-MM-DD HH:mm。分别测试标题完整和截断的条目；截断时下方应补完整标题。
3. 对照文件夹原提示，确认文件数与目录数一致，包括嵌套目录及空目录；目录数不计当前目录本身。验证完整/截断目录标题，确认目录同样只有一个提示。
4. 确认中文、多行、Markdown/HTML 字面文本、长备注滚动及窗口边缘可读。文件夹和文件均使用 Obsidian 当前语言的官方信息。
5. 无备注对象应保留官方内容与行为，允许额外等待读取判定；Vault 根目录和 descript.ion 不被接管。悬浮其他工具栏按钮时原有提示不受影响。
6. 在 TC 修改和删除备注后移出再悬浮，确认新备注更新，删除后恢复官方提示。读取失败或未知程序标记只显示原因和官方信息，不显示错误解码内容且文件不变。
7. 启用 Page preview，并按该功能设置使用修饰键悬浮笔记；确认有备注和无备注时预览均正常，不重复触发。
8. 快速切换条目、从条目移入提示再移回、滚动文件树、折叠/展开目录；确认无旧内容、重复或残留。提示内滚动应保持提示可读。
9. 显示时禁用插件，确认提示消失；多次启用后不重复。离开条目或禁用时若读取仍未完成，之后也不得出现提示。
